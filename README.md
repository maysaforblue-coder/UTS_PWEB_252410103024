Lobby. - Monitoring Rental PlayStation 

Website Lobby. adalah sistem pemantauan slot ketersediaan konsol PlayStation serta jadwal sewa secara langsung. Web ini dibuat untuk mengatasi permasalahan ketidakpastian ketersediaan unit rental, sehingga para pengunjung dapat mengecek stasiun konsol yang kosong, rincian game yang terpasang, serta tarif sewa per jam sebelum memutuskan berangkat ke lokasi rental.
